# 캐릭터 모션 기획 (2026-11-15)

사용자 요청: "캐릭터 모션을 최대한 귀엽고 다양하게 설계 기획하고 적용해줘".
그림(PNG 7장: 대기·듣기·생각·말하기 3단 입·눈 감음)은 그대로 쓴다. 움직임은 화면 코드(`src/server/public/motion.js`)로 만든다.

## 원칙

- 귀여움의 3요소: **눌렸다 늘어나기**(squash & stretch), **통통 튀는 박자**, **작은 감정 표시**(하트·반짝이·물음표 등).
- 같은 동작을 연달아 하지 않는다. 대기 중 잔동작은 7~15초마다 무작위로 고른다.
- 토스 기기(RK3399)를 생각해 `transform`·`opacity`만 움직인다. 감정 표시는 한 번에 최대 6개.
- "움직임 줄이기"를 켠 기기, 쉬는 화면에서는 모두 멈춘다(감정 표시도 안 나옴).
- 움직임은 상태를 글로도 함께 알린다(상태 줄·말풍선). 움직임만으로 뜻을 전하지 않는다.

## 겹(레이어)

| 겹 | 맡는 일 |
| --- | --- |
| `#face` | 상태별 반복(숨쉬기·귀 기울이기·갸웃거리며 생각) |
| `.fx` | 한 번 하는 동작(아래 목록). 새 동작이 오면 우선순위가 같거나 높을 때만 바꾼다 |
| `.body` | 립싱크 들썩임·목소리 크기 반응(기존) |
| `.emotes` | 머리 위 감정 표시(하트·반짝이·별·음표·땀·Zzz·?·!) |
| `.ground` | 뛰어오를 때 그림자가 작아졌다 커짐 |

## 상태별 반복

| 상태 | 움직임 |
| --- | --- |
| 대기 | 천천히 숨쉬기 + 7~15초마다 잔동작 |
| 듣기 | 몸을 살짝 기울여 귀 기울이기 + 목소리 크기만큼 커짐(기존) |
| 생각 | 좌우로 갸웃 + 머리 위 생각 점 세 개 |
| 말하기 | 입 3단 립싱크 + 들썩임(기존) + 답 내용에 맞는 감정 표시 |

## 답 내용에 맞춘 반응

답을 말하기 시작할 때 한 번만 고른다(앞에서부터 처음 맞는 것).

1. 축하·좋아·최고·멋져·대단·신나 → 콩콩 + 반짝이
2. 고마워·감사·귀여·사랑·칭찬 → 수줍 + 하트
3. 미안·죄송·아쉽·슬퍼·모르겠·못 찾 → 시무룩(가볍게) + 땀
4. 노래·음악·♪ → 둠칫 + 음표
5. 물음표로 끝남 → 갸웃 + ?

## 친구별 성격(속도·잔동작 비율)

| 성격 | 친구 | 속도 | 잔동작 간격 | 자주 하는 것 |
| --- | --- | --- | --- | --- |
| 느긋 | 늘보·카피 | 1.4배 느림 | 1.4배 길게 | 기지개·꾸벅·갸웃 |
| 활발 | 토리·콩이·몽이·솔이 | 0.8배(빠름) | 0.7배 짧게 | 콩콩·꼬물꼬물·빙그르 |
| 수줍 | 기니·나비 | 보통 | 보통 | 갸웃·수줍·두리번 |
| 보통 | 자비·곰돌·여우비·그 밖 | 보통 | 보통 | 고르게 |

## 얼굴 누르기(쓰다듬기)

1.5초 안에 누른 횟수로 반응이 커진다: 1번 꼬물꼬물 → 2번 콩콩 → 3번 이상 빙그르.
말풍선에 짧은 말(히히·간지러워요!·헤헤·왜 불러요?)을 띄운다. 소리는 내지 않는다.

## 검사

- `test/motion.test.js`: 답 내용 → 반응 고르기, 잔동작 고르기(연속 같은 동작 없음, 성격 비율), 성격 찾기, 누르기 단계, 감정 표시 개수 제한.
- 화면 확인: 헤드리스 Edge에서 각 동작 클래스가 붙고 끝나면 지워지는지, 움직임 줄이기에서 아무것도 안 붙는지.
