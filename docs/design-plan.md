# JARVIS 디자인 계획 (v4, 2026-11-14)

사용자 지시: "피그마, 힉스필드 모두 사용해도 된다. 디자인 계획을 잡고 진행한다."

## 1. 목표

- 토스 기기·휴대폰에서 멀리서도 한눈에 보이는 캐릭터 비서 화면.
- 새로 생긴 기능(부르면 대답하기·오늘 브리핑·스킬·승인 단계·PC 점검)을 같은 규칙의 부품으로 정리.
- 그림 없는 지금의 도형 얼굴 대신, 저작권 걱정 없는 **오리지널 캐릭터 그림**을 기본으로 제공. 치이카와·산리오 그림은 만들지 않는다(사용자가 권리 있는 그림을 직접 넣는 기능은 그대로).

## 2. 원칙

- 지금 쓰는 색·간격 값(따뜻한 크림 바탕, 주황 강조, 카드 24px 둥글기, 8단위 간격, 누르는 곳 44px 이상)을 그대로 이어받아 Figma 변수로 만든다. 밝은 화면·어두운 화면 둘 다.
- 상태는 색 하나로만 알리지 않는다: 글자·아이콘·움직임을 함께 쓴다(듣는 중·생각 중·말하는 중·쉬는 중·부르면 대답하기 켜짐).
- 글자 굵기는 600까지, 한글은 줄 간격 1.5 이상.
- 동의·지우기 같은 중요한 창은 처음 초점이 "취소".

## 3. 만들 것

| 도구 | 만들 것 |
|---|---|
| Higgsfield | 오리지널 캐릭터 "자비"(귤에서 떠올린 둥근 몸, 잎사귀 하나, 짧은 팔) — 대기·듣는 중·생각 중·말하는 중 1·2, 모두 같은 모양에 투명 바탕. 앱 아이콘 후보 |
| Figma | 파일 "JARVIS Hybrid 2.0 — 디자인": 00 계획 / 01 기초(색·간격·둥글기·글자 변수, 밝음·어두움) / 02 부품(단추 4종, 둥근 아이콘 단추, 카드, 배지, 체크·입력·오류, 확인 창, 말풍선, 요약 타일) / 03 화면(자비스 대기·듣는 중·대답, 쉬는 화면, 오늘 브리핑, 설정 스킬 탭·동의 창) / 04 캐릭터(자비 상태 시트) |
| 코드 | 자비 그림을 앱에 기본 캐릭터로 넣기("목록에서 고르기"에 "자비" 추가, 고르면 그림 얼굴 5장이 바로 적용), Figma에서 정한 값과 화면 맞추기 |

## 4. 순서

1. Higgsfield로 자비 기본 모습 4안 → 1안 고르기 → 같은 모습으로 상태 4장 더(기본 모습을 참고 그림으로 씀).
2. Figma 파일 만들기 → 기초 변수 → 부품 → 화면 → 캐릭터 시트.
3. 앱에 반영 → 시험 → 화면 캡처.
